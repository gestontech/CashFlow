# CashFlow

Prototype SaaS de gestion commerciale.

## Fonctionnalités de cette version
- Landing page responsive
- Mode clair/sombre automatique selon le système
- Design Liquid Glass professionnel
- Tarifs Gratuit / Pro / Élite
- Pages connexion et inscription (interface uniquement)
- Structure prête pour connecter un backend

## Lancer
Ouvrir `index.html` dans un navigateur ou servir le dossier avec un serveur statique.

## Prochaine étape
Connecter l'authentification, la base de données, les ventes, le stock, les clients, les dettes, les rapports et les paiements d'abonnement.
